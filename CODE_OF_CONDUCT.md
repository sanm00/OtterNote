# Code of Conduct

Be decent to each other. This project is for anyone who wants to use, ask about
or improve OtterNote, whatever their experience, background or identity.

That rules out harassment, insults, personal attacks, discrimination, unwanted
sexual attention, and publishing anyone's private information. Disagreeing with
an idea is fine; going after the person is not.

## Reporting

Tell the maintainer if someone is making the project hostile:

- Open an issue at <https://github.com/sanm00/OtterNote/issues> if the report can be public.
- Use a [private security advisory](https://github.com/sanm00/OtterNote/security/advisories/new)
  or [report abuse to GitHub](https://github.com/contact/report-abuse) if it needs to stay private.

Reports go only to the maintainer and are kept confidential. Depending on what
happened, the response may be a warning, editing or removing comments, closing
issues, or blocking the account from the repository.
